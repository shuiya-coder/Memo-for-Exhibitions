# 出品作品メモ

- アプリ名：出品作品メモ
- 概要：展覧会の出品目録（PDF）を読み込み、作品ごとに独立したメモページを作るツールです。同じ作品のメモを手動でまとめ（リンク）、並べて見比べることができます。タグ、検索、お気に入り、鑑賞日、参考文献、画像の添付にも対応しています。
- 授業「歴史情報学入門」で作った、ブラウザだけで動く（HTML/CSS/JavaScript）アプリです。GitHub Pages で公開できる形を目指しています。

## 使い方

### 起動と終了

1. このフォルダにターミナルで移動する
2. サーバーを起動する（授業用の `server.py` を使います。書き換えません）
   - Windows：`python server.py`
   - Mac / Linux：`python3 server.py`
3. ブラウザで `http://localhost:3000/` を開く
4. 止めるときは、ターミナルで `Ctrl + C`

### アプリの操作

| やりたいこと | 操作 |
|---|---|
| メモを作る | 一覧の「＋ 新しいメモ」。作品名・展覧会名・鑑賞日・出品目録の情報・メモ・参考文献を書いて「保存」 |
| PDF から一括でメモを作る | 一覧の「PDFを取り込む」（下の「PDF の取り込み」を参照） |
| タグを付ける | メモ画面の「タグ」欄に入力して Enter。一覧のタグボタンで絞り込める |
| 検索する | 一覧の検索ボックス。作品名・展覧会名・目録情報・メモ・参考文献・タグを横断して探す。空白で区切ると、すべてを含むメモだけが残る |
| お気に入り | 一覧の☆を押す（★になる）。「お気に入りだけ表示」で絞り込める |
| 同じ作品のメモをまとめる | メモ画面の「リンク」欄で、相手を検索して「同一作品」でつなぐ。A=B、B=C なら A=C とみなす |
| 関連する作品をつなぐ | 同じ「リンク」欄で「関連作品」でつなぐ（A-B、B-C でも、A-C は自動ではつながらない） |
| 並べて見比べる | 同一作品のメモがあると出る「同じ作品のメモを並べて見比べる」。違いのある項目が黄色で強調される |
| 画像を付ける | メモ画面の「画像」欄で、ファイルを選ぶかドラッグする（保存済みのメモのみ） |
| まとめて削除する | 一覧のメモ左のチェックで選び、「選択したメモを削除」 |
| バックアップ | 一覧の「JSONに書き出す」「JSONを読み込む」 |

### PDF の取り込み

PDF は、このパソコンのブラウザの中だけで読み込まれ、外部には送られません。

1. 一覧の「PDFを取り込む」を開き、PDF を選ぶ
2. 「目録の形式」を選ぶ
   - **表形式**：作品が行と列に並んでいる目録。見出しの文字（「作品名」「所蔵者」など）から、列の並びを自動で設定する。うまくいかないときは、列の内容と左端（x座標）を手で直すか、「見出しを手動で選んで、列を設定する」を使う。「全ページを作品に分ける」で読み取る。
   - **段組みカード形式**：作品ごとのまとまりが縦の段に並んでいる目録（例：大徳寺の目録）。大きい連番の数字を作品番号として段を見つける。「項目に分けて、確認・登録へ進む」で読み取る。
3. 「読み取り結果の確認と登録」の表で内容を確認し、直す（表の中身はその場で直せる。登録しない作品は「登録」のチェックを外す。「要確認」の列は、うまく分けられなかった理由）
4. 展覧会名（必須）、鑑賞日・共通タグ・所蔵者が空欄のときの補足（任意）を入れて「メモとして登録」

同じ展覧会名・番号・作品名のメモがすでにあれば、重複して登録しません。

### データの保存場所

- メモと画像は、**使っているブラウザの中**（IndexedDB）に保存されます。ブラウザのデータを消すと、メモも消えます。**こまめに「JSONに書き出す」でバックアップしてください。**
- `http://localhost:3000/` と、GitHub Pages で公開したページは、ブラウザから見ると別の場所なので、保存されたメモは共有されません。移すときは、JSON の書き出し・読み込みを使います。

### GitHub Pages で公開するとき

- すべてのファイルがこのフォルダ直下の静的ファイルです。リンクは相対パスで書いてあるので、`https://ユーザー名.github.io/リポジトリ名/` のようなアドレスでも動きます。
- 公開したページを開いた人は、**自分のブラウザの中**に、自分用のメモを作ります（あなたのメモは見えません）。
- PDF の読み取りには、PDF.js を CDN から読み込むため、インターネットへの接続が必要です。
- 出品目録の PDF や、メモに付けた画像は、このリポジトリに含まれていません。公開しているのは、アプリ（HTML/CSS/JavaScript）だけです。

## 既知の制限

- `http://localhost:3000/` で動くのは自分のパソコンだけです（他の人は見られません）。
- 名前が `.` で始まるファイルやフォルダ（`.claude`、`.git` など）は、サーバーから見えません。
- サーバーが動いていないと、ページが開かず、データも読めません。
- **メモと画像は、使っているブラウザにだけ保存されます。** ブラウザのデータを消すと失われるので、バックアップ（JSON の書き出し）が必要です。
- **展示期間（前期・中期・後期など）は取り込めません。** 文字ではなく塗りつぶしで描かれている目録があるためです。段組みカード形式では、展示期間の行は取り込まず、「元のテキスト」にだけ残ります。
- PDF の読み取りは、目録の書式に合わせたルールです。**別の書式の目録では、うまくいかないことがあります。**
  - 表形式：列は、文字の位置（x座標）で分けます。作品の内容が行の高さの中央に置かれている目録を前提にしています。
  - 段組みカード形式：作品番号が、大きい連番の数字で、段の左端に並んでいることを前提にしています。作品名の次の行が作者名、員数の行（「1 幅」など）が目印、という大徳寺の目録の書き方に合わせています。作品名が複数行で作者名がない作品は、作者名に作品名の続きが入ることがあります。
  - 画像だけの PDF（スキャンしたもの）は、文字が取れないため読み取れません。
- 画像は、PNG・JPEG・WebP・GIF に対応しています。iPhone の写真（HEIC 形式）は、読み込めません。大きな写真は、長辺 1600 ピクセルに縮小して保存されます。画像を含めた JSON は、ファイルが大きくなります。
- PDF.js は、インターネット上の CDN から読み込みます。オフラインでは、PDF の取り込みができません。
- メモ画面のリンク候補（作品名が同じメモ）は、全角・半角と大文字・小文字の違いは吸収しますが、それ以外の表記ゆれ（旧字体、送りがななど）は吸収しません。
